# Windows で動かす

## 用意するもの

- Windows のパソコン（CPU だけで動きます）
- Webカメラ（USB）とプロジェクター（HDMI などでつなぎ、「拡張」表示にする）
- Node.js 22 以上（https://nodejs.org/ja の「LTS」を入れる）
- Google Chrome
- Claude Code（https://code.claude.com/docs/ja/quickstart の手順で入れ、`claude` を打ってご自分の Claude の契約でログインしておく）

## 初回だけ

1. この置き場所を手元に置く（GitHub の「Code」→「Download ZIP」で展開してもよい）
2. そのフォルダで PowerShell を開き、`npm install` を打つ

## いちばん簡単な起動

フォルダの中の **`start.bat` をダブルクリック**します。初回は準備に1〜2分かかり、そのあと Chrome が自動で開きます。
黒い画面は閉じないでください（閉じると止まります）。展示の後は **`review.bat`** をダブルクリックすると振り返りが行われます。

カメラやプロジェクターが無くても、マウスや指が手の代わりになります（押すと光がはじけ、鈴が鳴る）。まずはこれで動きを確かめられます。

## 毎回の起動（手で打つ場合）

1. `npm start` を打つ。Claude Code にログインしていれば、Claude が場面を選びます（API の鍵は要りません）。
   「準備できました」と出るまで30秒ほど待つ。つながらないときは、言葉のキーワードで場面が切り替わります
   - Claude を使わずに動かすとき: 先に `$env:ISHI_BRAIN = "off"`
2. Chrome で `http://localhost:8787` を開き、そのウィンドウをプロジェクターの画面へ移す
3. 「カメラを起動して始める」を押し、カメラの使用を許可する
4. `F` で全画面、`M` で四隅の補正（四隅の丸をドラッグして壁に合わせ、もう一度 `M`）。補正はこのパソコンに保存され、次回も使われる
5. 「音を鳴らす」を押すと、場面に合わせた音が鳴る（ブラウザの決まりで、最初の1回はボタンを押す必要があります）。音量は横の目盛りで変える
6. `H` で操作板を隠す。「声を聞く」で来場者の声を拾う（声は端末の中で文字にする設定にしてあります。古い Chrome では外部へ送られることがあります）

## 展示の後

```
npm run review
```

その日の記録から効いた場面を測り、振り返り役のエージェントが場面の設定（色・速さ・キーワード）を直します。1分ほどかかります。
何を・なぜ変えたかは `docs/agent/改善記録/` に残り、直した設定は `config/presets.json` に入って次の `npm start` から使われます。
元に戻したいときは `config/presets.json` を消してください。

## 背景に動画や画像を映す

1. フォルダの中の `media` に、場面の名前のフォルダを作る（例: `media\rain`。名前の一覧は `media\README.md`）
2. その中に動画（mp4・webm）や画像（jpg・png・webp）を入れる。全部の場面に使うものは `media\all` に入れる
3. 場面が変わると、背景が切り替わる。濃さは操作板の「背景」の目盛りで変える

起動し直す必要はありません。素材は、この置き場所（GitHub）には上がらない設定にしてあります。

## 新しい場面を作る

```
npm run create -- "オーロラみたいにゆらめいて、手を近づけると波打つ光"
```

1分ほどで新しい場面ができ、`npm start` し直すと使えます。言葉のキーワードも一緒に作られます。
合わなければ `config/forms/<名前>.json` を消してください。作った記録は `docs/agent/場面づくり.md` に残ります。

## 動画も映すとき（MapMap）

1. MapMap で層を作り、名前を場面の名前（`flow` `bloom` `swarm` `rain` `orbit`）で始める
2. MapMap の設定で OSC の受信を有効にする（初期値は 12345 番）
3. 起動の前に `$env:MAPMAP_PORT = "12345"` を設定してから `npm start`

場面が変わると、その名前の層だけが見えるようになります。MapMap の版によって命令の書き方が違うので、
効かないときは `config/mapmap.json` の `style` を `dev` に変えてください。

## 展示を自動で動かす

1. 一度 `start.bat` で動かし、四隅の補正を済ませておく
2. `config\show.example.json` を写して `config\show.json` を作り、時間を書く
   - `open` と `close`: 開く時刻と閉まる時刻（例 `"10:00"` と `"18:00"`。夜をまたいでもよい）
   - `days`: 開く曜日（1=月 … 7=日）
   - `screenX`: プロジェクターが2枚目の画面なら、1枚目の画面の幅（例 1920）。1枚だけなら 0
   - `show.json` が無ければ、いつでも開いている（手で止めるまで動く）
3. **`show.bat` をダブルクリック**。展示用の Chrome が全画面で開き、カメラと音が自動で始まる
   - 初回だけ、カメラの許可を求められたら「許可」を押す（次からは聞かれない）
   - 四隅の補正は展示用の Chrome にもう一度だけ必要（`M` キー。補正が済んだら `Alt+F4` で閉じて `show.bat` を開き直す）
4. 閉まる時刻になると暗くなって音が止まり、その日の振り返りが自動で行われる。開く時刻になると、また映る
5. パソコンにサインインしたら自動で始めたいときは **`autostart-on.bat`** を一度開く。やめるときは `autostart-off.bat`
6. Windows の設定で「スリープしない」「画面を消さない」にしておく（設定 → システム → 電源）

止めるときは、展示用の Chrome で `Alt+F4`、黒い画面を閉じる。

## 困ったとき

- カメラが映らない: Chrome のアドレス欄の左の印から、カメラを「許可」にする
- 動きが重い: カメラの前の人を減らすか、粒の数が少ない場面にする（パソコンの性能による）
- 投影の光がカメラに映り込み、手を読み違える: カメラを投影面から外した向きに置く
