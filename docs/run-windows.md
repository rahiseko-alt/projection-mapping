# Windows で動かす

## 用意するもの

- Windows のパソコン（CPU だけで動きます）
- Webカメラ（USB）とプロジェクター（HDMI などでつなぎ、「拡張」表示にする）
- Node.js 22 以上（https://nodejs.org/ja の「LTS」を入れる）
- Google Chrome
- Claude Code（https://code.claude.com/docs/ja/quickstart の手順で入れ、`claude` を打ってご自分の Claude の契約でログインしておく）

## 初回だけ

1. この置き場所を手元に置く（GitHub の「Code」→「Download ZIP」で展開してもよい）
2. そのフォルダで PowerShell を開き、`npm install` を打つ

## 毎回の起動

1. `npm start` を打つ。Claude Code にログインしていれば、Claude が場面を選びます（API の鍵は要りません）。
   「準備できました」と出るまで30秒ほど待つ。つながらないときは、言葉のキーワードで場面が切り替わります
   - Claude を使わずに動かすとき: 先に `$env:ISHI_BRAIN = "off"`
2. Chrome で `http://localhost:8787` を開き、そのウィンドウをプロジェクターの画面へ移す
3. 「カメラを起動して始める」を押し、カメラの使用を許可する
4. `F` で全画面、`M` で四隅の補正（四隅の丸をドラッグして壁に合わせ、もう一度 `M`）。補正はこのパソコンに保存され、次回も使われる
5. `H` で操作板を隠す。「声を聞く」で来場者の声を拾う（声は端末の中で文字にする設定にしてあります。古い Chrome では外部へ送られることがあります）

## 展示の後

```
npm run review
```

その日の記録から効いた場面を測り、次の展示に反映します。結果は `docs/agent/改善記録/` に残ります。

## 動画も映すとき（MapMap）

1. MapMap で層を作り、名前を場面の名前（`flow` `bloom` `swarm` `rain` `orbit`）で始める
2. MapMap の設定で OSC の受信を有効にする（初期値は 12345 番）
3. 起動の前に `$env:MAPMAP_PORT = "12345"` を設定してから `npm start`

場面が変わると、その名前の層だけが見えるようになります。MapMap の版によって命令の書き方が違うので、
効かないときは `config/mapmap.json` の `style` を `dev` に変えてください。

## 困ったとき

- カメラが映らない: Chrome のアドレス欄の左の印から、カメラを「許可」にする
- 動きが重い: カメラの前の人を減らすか、粒の数が少ない場面にする（パソコンの性能による）
- 投影の光がカメラに映り込み、手を読み違える: カメラを投影面から外した向きに置く
